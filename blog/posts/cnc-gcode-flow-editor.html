Designing a G-code Flow Editor for CNC Control

Jun 15, 2026 · Automation · CNC

Controlling a CNC machine over serial is straightforward — send G-code, read responses. Building something professionals actually use is harder. Here is the design that worked.

Start with the serial layer

A rock-solid serial terminal is the foundation. Every other feature — jogging, homing, flow execution — is just structured serial I/O. I abstracted it behind a backend interface so a mock serial mode works without hardware.

Jog and home, then automate

Real-time jog controls and homing sequences cover interactive use. But the value is the flow editor: a line-by-line list of G-code steps you can build, reorder and run as an automated routine.

Reference, not memorise

Nobody remembers every G/M-code. A built-in code reference browser means the tool is self-contained — no alt-tabbing to documentation mid-flow.

Persistence and shipping

Flows save as .gcode files and reload later. Distribution is automated with a GitHub Actions release workflow that builds for Windows, macOS and Linux.

Open source: CNC_robot_control.
