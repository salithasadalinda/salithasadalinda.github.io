Training YOLOv8 on a Custom Dataset

Aug 4, 2026 · Computer Vision

Object detection starts with data. This post covers the pipeline I use for training YOLOv8 models on custom datasets — from folder layout to evaluating the trained weights.

Dataset layout

Ultralytics expects a specific directory structure. Images and labels live in train, val and test splits, with a data.yaml pointing to them: 

dataset/
  train/
    images/  labels/
  val/
    images/  labels/
  data.yaml

data.yaml

Point the config at the splits and declare your classes:

path: dataset
train: train/images
val: val/images

names:
  0: target_class

Training

from ultralytics import YOLO

model = YOLO("yolov8m.pt")
model.train(data="data.yaml", epochs=50, imgsz=640)

Evaluation

The training run produces runs/detect/train with metrics, confusion matrix and PR curves. I compare mAP@0.5 and mAP@0.5:0.95 to judge whether the model is overfitting or underfitting, then adjust epochs and data augmentation.

That model then becomes the detector used by the rest of the pipeline — in my case, on-device inference on an ESP-32 for the AgriGuard project.
