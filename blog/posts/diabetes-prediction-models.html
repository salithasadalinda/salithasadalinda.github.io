Comparing ML Models for Diabetes Prediction

May 2, 2026 · Machine Learning

When a dataset is small, the temptation is to reach for the biggest model. In this project I compared several classifiers on the same diabetes dataset to see which actually wins.

The baseline

Start with something boring: logistic regression or a decision tree. The baseline tells you how much headroom there is before you burn hours tuning.

What I compared

  • Logistic Regression
  • Decision Tree
  • Random Forest
  • Support Vector Machine
  • K-Nearest Neighbours

What mattered

For medical-style classification, accuracy alone is misleading. Precision, recall and the confusion matrix matter more — a false negative costs more than a false positive. Ensemble methods won on recall while simple models stayed competitive, which is the usual story on structured tabular data.

Takeaway

Evaluate baselines first, use the right metric for the domain, and don't over-engineer. The notebook is in diabetis_prediction.
